How to Get the Badge

1. Go to the GitHub Developer Program registration page (developer.github.com/program/).
2. Enter your email and a product/company website URL (any project you maintain).
3. Once accepted, the Developer Program Member badge appears automatically on your GitHub profile.

Requirements: You need an integration in production or development using the GitHub API. The program is free to join and gives you early access to API changes and GitHub Enterprise development licenses.
